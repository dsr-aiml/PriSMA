# Environment

| Variable | Required now | Default / role |
| --- | --- | --- |
| POSTGRES_PASSWORD | Yes | Generated by setup-env.sh; use URL-safe characters because it is embedded in DATABASE_URL |
| POSTGRES_USER | No | prisma |
| POSTGRES_DB | No | prisma |
| PUBLIC_ORIGIN | Yes for browser writes | http://localhost:3000; must match address used in the browser exactly |
| COOKIE_SECURE | No | false for local HTTP; true only behind HTTPS |
| SESSION_DAYS | No | 7 |
| DEMO_STEP_SECONDS | No | 0.8, bounded to 0–5 in worker |
| TINYFISH_API_KEY | Only for web assessment | Private Search/Fetch key; requires TINYFISH_ENABLED=true |
| TINYFISH_ENABLED | No | false; explicit Search/Fetch enablement |
| DATABASE_URL | Container-generated | PostgreSQL URI; can override for local backend development/tests |
| REDIS_URL | Container-generated | redis://redis:6379/0 |
| API_INTERNAL_URL | Frontend runtime | http://api:8000 in Compose; http://localhost:8000 outside Compose |

Root `.env` is read by Compose for interpolation. Only explicitly declared variables are passed into containers. Gemini settings are passed only to backend services; hosted execution requires explicit enablement. TinyFish settings reach backend services only. Never commit `.env`.

Changing PostgreSQL initialization values after volumes exist does not modify existing database credentials. Keep the generated password for that volume or deliberately migrate credentials; do not delete volumes to resolve a config issue unless losing local data is intended.

Changing backend environment values requires recreating API/worker/research, not merely refreshing the browser. Existing .env is preserved during upgrades; add new optional values manually only when needed. Model readiness checks validate local availability or hosted configuration; they do not perform an inference test. See local-inference.md.

## Collection and profile controls

| Variable | Default / role |
| --- | --- |
| TINYFISH_SEARCH_DAILY_LIMIT | 100, shared UTC-day attempts for this key within PriSMA |
| TINYFISH_FETCH_DAILY_LIMIT | 200 URL attempts, including retries/failures |
| TINYFISH_CACHE_SECONDS | 3600, user-scoped response TTL; 0 disables reuse |
| TINYFISH_SEARCHES_PER_RUN | 1; configured maximum 1–5; queries include cached responses |
| TINYFISH_FETCH_ATTEMPTS_PER_RUN | 6; configured maximum 1–20; also bounds distinct visited URLs; retries consume new attempts |
| ALLOW_LARGE_LOCAL_MODELS | false |
| OLLAMA_BALANCED_MODEL / OLLAMA_ADVANCED_MODEL | Empty; explicit installed model tags |
| INFERENCE_MEMORY_BUDGET_BYTES | 3000000000, conservative model working-memory admission budget |
| OLLAMA_MEMORY_LIMIT | 3g, actual container RAM/swap cap; keep aligned with the admission budget |
| OLLAMA_CPU_LIMIT | 3, actual container CPU cap |
| LOCAL_GPU_LAYERS | 0 CPU default; -1 requests offload, requiring independently configured device access |
| ANALYSIS_MAX_PASSAGES | 48, round-robin extraction coverage; all chunks remain saved |

Large weight caps default to 5 GB (Balanced) and 10 GB (Advanced); model weight limits are not available RAM or VRAM. CPU thread/context/output bounds remain conservative for every profile. Optional NVIDIA access is in compose.nvidia.yaml and is never enabled automatically.

## Research scheduling

`RESEARCH_TIMEOUT_SECONDS` defaults to 45 (15–90 seconds) and is passed to backend services by Compose. `WORKER_QUEUES` selects worker queues: investigations for the main worker, research for the dedicated Research service. Query enablement/model/key remain independent of the assessment engine. Browser inspection has its own optional profile and does not contact a paid remote browser provider.

Research 0.8.1: GEMINI_QUERY_CONTEXT_TOKENS=32768, GEMINI_QUERY_OUTPUT_TOKENS=3000, GEMINI_QUERY_RPM=6, GEMINI_QUERY_INPUT_TPM=120000, optional GEMINI_QUOTA_PROJECT, RESEARCH_MAX_WAIT_SECONDS=65, RESEARCH_TOTAL_SECONDS=180 and RESEARCH_RETRY_ATTEMPTS=3. These are defaults; existing explicit .env settings remain unchanged. Match the quota settings to the active project/model limits. See [Research](research-queries.md).
