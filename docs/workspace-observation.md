# Research workspace

Reference and actual assessments use the same dashboard components. The Atlas reference is derived from the versioned source bundle in `backend/fixtures/atlas-sources.json` through the ordinary structural parsers, citation checks and repository scanners. Complete coverage includes eleven sources, five source modules, an API contract with three resource schemas, architecture declarations and commercial terms. Reference queries live only in the current page state. Reference reads, questions and exports create no database rows, queued jobs or saved history. The legacy Atlas fixture is isolated from real collection and retained for earlier report compatibility.

The map uses a compact component card, routed edge labels, wider layer spacing and a fit range suitable for large inventories. **Isolate focus** keeps a component and its directly linked neighbourhood in view. Source strength is available in the evidence inspector rather than filling every card. The full directory retains all components and relationships.

The repository index aligns filename, parent path and parser status within a consistently sized row. The source and declaration explorers retain their existing links. Insights use consistent observation cards and a responsive source-support matrix. Matrix rows expand to fit text; identical source content is grouped, and source windows adjust to available width.

The landing retains Orbitron display text, Geist interface text and the existing theme icons. Its layered illustration is vector/CSS geometry with larger staging, finer paths, subtle signal movement and directional white/cool-grey lighting. Dark palette tokens remain unchanged. Reduced-motion and offscreen/hidden-page pauses are respected. No image or animation asset needs to be supplied.


Research uses one server-managed Google Flash-Lite answer path. Answers appear as concise source-cited paragraphs; records, raw passages and method details are expandable. Assessment engines and historical model selections remain unchanged. See [research setup](research-queries.md).
